## Aplicación desplegada

La aplicación está disponible en:

**https://pokemon.happyminecraft.org**

La aplicación consume la API desplegada en:

**https://pokemon-api.happyminecraft.org**

### Funcionalidades principales

- Búsqueda de Pokémon mediante PokéAPI
- Registro e inicio de sesión
- Autenticación con JWT
- Persistencia de sesión
- Ruta protegida de favoritos
- Guardar y eliminar Pokémon favoritos
- Diseño responsive
